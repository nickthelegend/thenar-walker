Before you start (read once)
  1. The ESP32-S3 runs firmware/arm_calibration (already flashed). PCA9685 on SDA 8, SCL 9, OE 10.
  2. Servo power: 6 V buck → PCA9685 V+ / GND, never from USB. Put a 470–1000 µF capacitor across V+/GND if you have one.
  3. Do one joint at a time. When you press Start this joint the servo jumps to its start pulse at full speed (a servo has no position sensor). Keep fingers and cables clear. ALL SERVOS OFF makes everything limp.
  4. Order: gripper → wrist roll → wrist flex → base pan → elbow → shoulder (light joints first, the heavy shoulder last).
  5. For each joint: jog to Reference A, press Set A; jog to Reference B, press Set B. The app works out zero, direction and µs per degree. Then jog to each safe end (stop 3–5° before anything touches) and press Set end twice. Test, then Mark joint done.
  6. When all 6 are done: Save to robot (stored on the ESP32) and copy calibration.h into firmware/thenar_walker_bot/.
  7. If the zero pulse lands outside about 1200–1800 µs, move the horn one spline tooth and redo the joint — otherwise one end of the range is too short.
